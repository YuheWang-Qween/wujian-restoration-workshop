# 走马楼三国吴简修复工坊
# 生成式人工智能赋能文博考古教学的应用场景建设报告

---

## 一、应用场景的建设过程与建设进度

### 1.1 建设背景与理念

1996年长沙走马楼J22古井出土十余万枚三国吴简，被誉为二十世纪中国最重要的简牍考古发现之一。然而，文物保护修复作为一门高度专业化的实践学科，其核心知识——"为什么这样修"的科学决策逻辑——长期沉淀于考古报告与修复档案之中，难以经由传统课堂讲授有效传递。学生面对的是结论，而非得出结论的过程；是文字，而非承载文字的文物本体。

本应用场景以《长沙走马楼三国吴简的保护与整理》等权威文献为内容基底，秉持**"让证据说话、让学生动手"**的核心理念，依托生成式人工智能技术，将真实的考古修复流程重构为一个可交互、可评阅、可回溯的沉浸式数字工坊，探索文化遗产数字化教学的新范式——学生不再是知识的旁观者，而是站在修复台前、面对原始数据独立作出专业判断的"修复师"。

### 1.2 建设过程：四个阶段、层层递进

**第一阶段：知识体系解构与教学内容谱系化（已完成）**

以考古报告原始数据为唯一内容来源，遵循"尊重工序、还原现场"的原则，将保护整理全流程解构为**揭取—清洗—绑夹与核对—饱水保存—脱色—脱水**六大环节，构建起与真实修复工作完全同构的课程知识图谱。每一环节设置"工序说明—关键数据—细问"三节进阶内容，细问全部从报告原始数据出发反向设计——如揭取环节呈现叠压关系的原始记录，要求学生依据层位学原理自行推定层序；清洗环节给出六道工序的工时统计，要求学生完成人力与工期的工程推演。

同步建成**简牍鉴赏展厅**，设"发现与归属、形制分类、主题释读、案例精读、关键术语"五大板块，内容出自资料汇编《长沙走马楼吴简：种类、主题与释读》，形成"动手修复+动眼鉴赏"双翼并展的场景格局。

建立 `wujian_knowledge` 知识库数据集（三册扫描文献），为AI助教的检索增强生成（RAG）奠定语料基础。

**第二阶段：技术底座搭建（已完成）**

采用 Next.js 16 App Router + React 19 + TypeScript 前沿技术栈与自定义服务端架构，构建高可用教学平台：

- 接入 Supabase 云数据库，实现用户认证体系与行级安全策略，保障教学数据安全合规；
- 深度集成豆包大语言模型（doubao-seed-2-0），支持文本与图像多模态输入，为画板作答等非文字题型的智能评阅提供模型能力；
- 构建"本地持久化+云端同步"双通道进度管理体系，学生任何时点退出均可无缝续接；
- 打造"纸墨"主题视觉系统（朱砂、赭石、竹青、墨色），以东方美学语言呼应简牍文物的历史气质，实现技术载体与文化内核的统一。

**第三阶段：AI助教与智能评阅系统开发（已完成）**

- 打造数字人向导**"小简"**：具备实时位置感知能力，可依据学生所处环节、浏览位置与作答记录动态切换引导策略；对话窗口支持流式输出（SSE）与知识库检索双引擎，实现"有据可依"的智能问答；
- 研发**"请小简评阅"**智能评阅系统：学生提交作答后，AI依据小问级评阅要点（rubrics）秒级给出"成立/部分成立/不成立"三档判定，并流式输出诊断式解析——肯定依据、点明缺口、指引方向，而绝不代端标准答案，贯彻"扶放有度"的教学法立场；
- 实现五种作答题型引擎：分层排序、单选判断、多选、左右匹配、画板作答（canvas画笔+多模态判分），覆盖从逻辑推演到空间表达的多元认知维度；
- 建成成就卡系统：以简册编联为意象设计结业证书，六枚竹简对应六道工序，朱砂落印，可下载存证。

**第四阶段：演示传播体系与持续优化（基本完成）**

开发内置演示模式：十八个场景自动播映，TTS语音旁白与界面操作逐帧同步，完整呈现"登录—双页签—六工序—AI对话—五题型—成就卡"的教学全链路，可直接用于课堂教学展示、新生引导与成果推广。同期完成多项体验优化：加载流程精简、LaTeX公式渲染、字体子集化、展厅交互统一化等。

## 二、应用场景在优化教学方面的具体实践

### 2.1 教学范式革新：从"结论灌输"到"证据推理"

本场景确立**"有数据处，从数据反推结论"**的教学设计总纲——所有题目不预设结论，而是将考古报告中的原始数据原汁原味地呈现给学生，由学生独立完成从证据到判断的完整推理链条。这一设计将科学考古"证据—推理—结论"的思维范式内嵌于每一次作答之中：

- **叠压排序题**：呈现层位叠压的原始记录，学生推定简牍层序。系统接受一切满足先后约束的合法解——传递"考古证据允许多解"的学科科学观，培养学生对不确定性的专业态度；
- **工时推演题**：基于六道工序真实工时数据，完成"人力减半、工期几何"的工程决策推演，让文物保护的经济性与科学性在数据中自然显现。

### 2.2 认知科学驱动：五种题型对应五种高阶思维

依据学习科学理论，题型设计系统覆盖布鲁姆认知目标分类的高阶层级：

| 题型 | 认知维度 | 能力指向 |
|------|---------|---------|
| 分层排序 | 空间逻辑推理 | 层位学原理的迁移应用 |
| 单选判断 | 批判性思维 | 陈述辨析与证据补充 |
| 多选 | 综合判断 | 多源信息的甄别筛选 |
| 匹配 | 关联建构 | 概念网络的体系化组织 |
| 画图作答 | 空间表达 | 知识外化的多模态输出 |

其中画板作答题由多模态大模型进行视觉评阅，突破传统在线教学仅能评价文字作答的局限，属生成式AI在教学评价领域的前沿应用。

### 2.3 人机协同评阅：大班教学中的"一人一师"

针对大班教学中教师难以逐一评阅开放性作答的长期痛点，本场景构建了**"AI即时评阅+教师主导设计"**的人机协同评价体系：

- **评价标准由教师主权掌控**：全部约60道细问均配有教师编制的小问级评阅要点，AI严格依此判定，确保评价的教育学立场；
- **反馈秒级抵达、全程伴随**：学生提交后数秒内获得"成立/部分成立/不成立"三档判定与流式诊断解析；
- **诊断而非代答**：评阅输出遵循"点依据—点缺口—指方向"的结构，始终坚持引导学生自主修正，杜绝AI直接给出标准答案，守护深度学习的发生条件。

由此，每位学生都拥有一位全天候在线、懂内容、懂进度的专属助教，形成性评价从"抽样"走向"全员、全程、全时"。

### 2.4 学习过程可续：面向深度任务的弹性学习支持

六环节约60道细问构成一项长周期深度学习任务，系统以三重机制保障学习过程的连续性与自主性：

1. **本地持久化**：草稿、评阅判定、画板图像、提交定稿全程自动保存，颗粒度精细至单题；
2. **云端无缝同步**：登录状态下进度实时上云，退出时强制同步，跨设备、跨时点学习记录零丢失；
3. **自主重做机制**：每环节支持一键清零重修，尊重学习者的自我修正权。

首页环节卡片实时呈现"已提交/已评阅"双维进度，使学习进程可视、可感、可控。

### 2.5 智能演示体系：赋能课堂教学与推广传播

十八场景演示模式配合TTS语音旁白，实现教学全流程的自动化演播——教师课堂展示、新生入学引导、对外成果汇报皆可直接调用，显著降低智能体教学应用的使用门槛。

### 2.6 成就认证设计：以文化意象承载学习激励

结业成就卡以"简册编联"这一古籍形制为设计母题：六枚竹简象征六道工序，朱砂印鉴落款认证，评阅统计四维呈现。学生完成全部环节、署名后方可解锁并下载PNG存证——将中华传统文书美学转化为学习成果的仪式化认证，实现激励功能与文化传承的一体两用。

## 三、与应用场景建设相关的其他成果

**1. 文博专题知识库数据集**：建成 `wujian_knowledge` 数据集，收录三册走马楼吴简文献，支持AI助教检索原文页面并以图像形式馈入多模态模型，实现严格基于文献的检索增强生成（RAG），是"AI幻觉治理"在文博教学领域的一次实践示范。

**2. 教学传播内容矩阵**：完成六幕结构叙事讲稿与配套演示视频脚本（八个场景，含画面编排与旁白文本），形成可复用的教学推广与成果展示素材体系。

**3. 文化主题视觉设计系统**：原创"纸墨"主题UI系统——朱砂（强调）、赭石（警示）、竹青（成立）、墨色（正文）的传统色彩语义体系，衬线字体子集化与纸墨肌理背景，为数字文博教学产品的美学表达提供了可迁移的设计范式。

**4. 结构化评阅要点体系**：为约60道细问逐题编制小问级评阅要点，既是AI评阅的判定依据，本身即构成一份高质量的结构化教学评价标准文档，可独立用于课堂教学评价。

**5. 内容质量保障机制**：线上内容与《走马楼吴简修复工坊_内容方案》逐段对照核验，建立"原始文献—教学设计—数字内容"三级一致性保障流程。

## 四、经费使用情况

本项目经费使用坚持**"能力优先、按需配置、绩效导向"**原则，重点投向智能算力与教学资源两大核心：

| 支出方向 | 用途说明 | 预算占比 |
|---------|---------|---------|
| 大模型算力服务 | AI助教对话、智能评阅、多模态判分的推理调用费用 | 约40% |
| 云基础设施 | 数据库存储、用户认证、应用部署与带宽保障 | 约25% |
| 教学内容建设 | 考古文献整理、题目设计、评阅要点编制、知识库建设 | 约20% |
| 产品研发迭代 | 界面设计、交互开发、多模态画板、演示系统 | 约10% |
| 测试与质量保障 | 性能优化、渲染兼容、体验打磨 | 约5% |

> 经费配置与建设绩效高度耦合：40%以上投入直接转化为学生端的智能评阅服务，20%沉淀为可复用的内容资产，确保每一笔支出均可对应可核验的建设产出。

## 五、下一步工作计划

### 5.1 近期（1—3个月）：夯实体验、深化内容

1. **移动端深度适配**：针对触屏交互重构画板题与匹配题的操作体验，覆盖碎片化学习场景；
2. **题库纵深扩充**：重点增设饱水保存与脱色环节的实验设计类细问，深化"从数据到结论"的证据推理训练。

### 5.2 中期（3—6个月）：数据驱动、生态延展

3. **学习分析研究**：基于积累的作答数据开展各环节错误率分布与典型迷思概念分析，反哺教学设计，形成"数据—诊断—改进"闭环；
4. **知识库扩容**：纳入更多走马楼及相关简牍研究文献，提升AI检索的覆盖面与准确度；
5. **场景矩阵复制**：以本场景为母版，规划建设里耶秦简、银雀山汉简等系列简牍修复工坊，形成"中华简牍数字教学工坊"矩阵。

### 5.3 远期（6个月以上）：模式创新、范式输出

6. **协作学习模式**：引入分组协作修复机制，模拟真实修复团队的分工协同，培养复合型文保人才；
7. **三维交互升级**：探索画板题向三维简牍操作界面的演进，让学生在虚拟空间中"亲手"揭取、翻转、清洗简牍，迈向具身化学习；
8. **框架开放输出**：将"题型引擎+评阅要点+AI判定"的智能评阅框架抽象为通用教学组件体系，向文博乃至更广泛的人文社科学科输出可复用的AI教学基座。

## 结语

从1996年J22古井中重见天日的十余万枚吴简，到今天学生指尖可触的数字修复台——本应用场景以生成式人工智能为桥梁，让沉睡的考古档案转化为活跃的教学现场。这条路的全部价值，正在于每一步都由学生自己走过；而智能体所做的，是确保他们走出的每一步，都有专业、即时、有温度的回响。
