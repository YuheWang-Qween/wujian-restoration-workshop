# 走马楼三国吴简 · 简牍修复工坊

一个教学智能体，分两篇：

- **简牍发掘**——已完成。按实际修复工序组织，**六道工序即六个环节，每个环节一个入口。**
- **简牍展示**——占位。环节划分与内容方案待补，页签在，内容暂未开放。

两块在大厅顶部同一行，用页签自由切换。下面讲的是「简牍发掘」。

| # | 环节 | 一句话定位 | 细问 |
|---|---|---|---|
| 一 | 揭取 | 唯一一道不可重来的工序 | 排序题 / 判断题 / 机理分析题 |
| 二 | 清洗 | 让字迹第一次真正可见 | 选择题 + 说明理由 / 工程试错分析题 / 工时反推题 |
| 三 | 绑夹与核对 | 身份不能在工序之间掉线（轻量环节） | 编号系统分析题 / 后果分析 + 方案设计题 |
| 四 | 饱水保存 | 持续时间最长、失控风险最隐性 | 假设排除题 / 多维决策题 / 排序题 + 机理分析 |
| 五 | 脱色 | 从「能保存」进入「能使用」 | 数据判读题 / 反常数据解释题 / 决策题 |
| 六 | 脱水 | 不可逆程度最高的一道 | 各向异性题 / 数据计算 + 材料分析题 / 流程决策题 |

共 17 道细问。每个环节页分三节：**为什么必须有这个环节**（含报告原始数据与数据表）、
**上机操作**（虚拟仿真工作台），以及**细问**；右侧是导师，逐问评阅。

## 上机操作：虚拟仿真工作台

六个环节各有一台工作台，排在细问之前——**先动手，再被追问**。不是选 A/B/C/D，
而是按真实工序排次序、挑工具、调参数、逐段推进：

| 环节 | 你在工作台上做什么 | 做错了会看到什么 |
|---|---|---|
| 一 揭取 | 排五个小坨的揭取次序、清横断面找缝、选竹刀尖、点蘸润滑、定 2～3 cm 步距逐段剥离、托举 | 次序违反已记录的叠压关系，层位信息当场作废；捏住一端提起来，简断在半空 |
| 二 清洗 | 定起手面、在三代工具里挑笔、调运笔力度、走完六道工序 | 力度出区间，竹黄面上仅存的墨迹被抹掉；双面有字不减速，那一面再也判不出有没有字 |
| 三 绑夹与核对 | 备棉线、选绑夹方式、按映射可信度排编号卡 | 选「不绑夹直接入槽」，复现 2003 年 7 月的漂移串槽事故 |
| 四 饱水保存 | 在六种药剂里选、配浓度、定换液周期、值守 24 个月 | 浓度压不住菌，第 10 个月长出白斑与黏液；再等一个周期就是软腐 |
| 五 脱色 | 配 EDTA、选还原试剂、调恒温槽、按分钟保温作用 | 温度掉出 45～50℃，罗维朋蓝色值停在高位不动；选硼氢化钠，简几分钟后漂在液面上 |
| 六 脱水 | 判材质、选填充材料、控熔融温度、定填充量、干燥 | 填充不到位，宽度收缩率冲过 5% 的指标线，字跟着被压扁 |

画面不是装饰，是反馈本身：竹片按真实形制画成细长条（长约 23 cm、宽 1 cm 出头），
弧面受光、走纤维纹、带编绳磨痕；简上的字是起收锋都收细的笔墨，字迹越散淡洇得越开；
饱水的简有湿面高光，脱水后转成十六醇的哑光颗粒。**简面上的笔画只是笔墨质感的模拟，
不是可释读的释文。**

四项指标（简体完整度 / 字迹可辨度 / 信息完整度 / 累计工时）随操作实时跳动，
走完出验收报告，附报告里实际的做法，可以重新开工。工具、参数区间与失败机制全部出自报告；
**指标的扣分幅度是教学权重，不是报告实测值**。这一节不判分、不计入进度——
产出是一份操作记录，可以一键带给导师，让他针对代价最大的那一步追问你。

每道细问底下有自己的答题框：写的内容实时存在本机（刷新不丢），点「提交给导师评阅」
就把这份答案连同题号推进右侧对话，导师据此评阅。旁边的「向导师提问」只是把题号填进输入框，
用来问问题而不是交答案。

## 智能体是怎么带教的

导师的行为写在 `src/lib/workshop/prompt.ts` 的总纲里，几条硬约束：

- **先答后评**：学习者没给答案之前不给答案、不给要点。
- **一次只推进一小问**，不把 (a)(b)(c) 一次性抛出。
- **计算题必须要过程**，只给数字的退回重做；口径（取中值、按几个工作日）要写明。
- **排序题必须问"哪些不可判定"**，排出唯一序列而不指出不可判定的单位对，是本类题的核心失分点。
- 评阅给「成立 / 部分成立 / 不成立」+ 依据 + 缺口，不打分数。
- 只用注入的报告数据，不编造数字与出处；报告本身口径有出入的地方主动说明。

每道细问的评阅要点放在 `src/lib/workshop/rubrics.ts`，**只走服务端**，不进浏览器包。

## 本地运行

```bash
pnpm install
pnpm dev
```

访问 http://localhost:5100 。

本地环境没有模型凭据时，导师会提示「导师未接通」并说明原因，环节资料与细问照常可读；
部署到 Coze 运行时后凭据自动注入。

## 数据来源

全部内容出自《长沙走马楼三国吴简的保护与整理》。报告不同章节之间存在口径差异的六处
（有字吴简总数、出土总数、大木简数量、坨数、纤维素结晶度、防腐药剂名），
已在大厅页「报告内部数字出入备案」里逐条列明本工坊采用哪一个口径。
